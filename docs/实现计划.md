# 《码上往生》实现计划

> **For agentic workers:** 本计划在当前会话内联执行（executing-plans 模式），任务用 checkbox 跟踪。设计依据：`docs/码上往生-设计方案.md`。

**Goal:** 实现一个 Next.js 单页应用「码上往生」——代码葬礼五幕仪式流 + OpenRouter 多模型悼词 PK + 讣告卡片导出，GitHub-ready。

**Architecture:** App Router 单页状态机（8 个 stage 串成五幕），3 个 API Route 代理 OpenRouter（key 仅存服务端环境变量），无数据库无用户系统。lib 层封装调用纪律（JSON mode + 正则兜底 + 超时 + 内存限流），全链路带离线演示兜底。

**Tech Stack:** Next.js 15 (App Router, TS) + Tailwind CSS 3 + Zod + html2canvas + Web Audio + Vitest

---

## 与设计文档的两处实现期决策

1. **PK 环节改为「每模型一个请求」**：客户端并行发 4 次 `POST /api/eulogy {model}`，谁先返回谁先打字机展示（真实交稿节奏），比单请求 allSettled 体验更好。单家失败显示「该殡葬师缺席」，全灭走 demo 兜底。
2. **限流改为 20 请求/分钟/IP**（一场葬礼最多 6 个请求，原 5 场/分钟不够 PK 用）。

## 任务清单

- [ ] T1 脚手架：手写配置文件（不跑 create-next-app，目录非空且避免交互），`npm install`
- [ ] T2 lib 层：types（会话状态/响应类型）→ causes（六大死因常量）→ models（阵容常量）→ prompts（人设+三环节 Prompt）→ schema（Zod + 宽松解析）→ openrouter（callJSON：20s 超时/json_object/失败重试去 response_format/正则截取）→ ratelimit（内存令牌桶）→ demoData → detectLanguage
- [ ] T3 API 路由 ×3：zod 校验入参 → 限流 → 调用 → 失败回落 demoData 并标记 `fallback: true`；`export const maxDuration = 60`
- [ ] T4 UI 组件（暗色葬礼主题）：CodeInput（粘贴/拖拽/行数/200 行截断）→ CausePicker（六宫格）→ LoadingRitual（文案轮播）→ AutopsyReport（分节浮现）→ PKArena（四墓碑竞写+投票）→ FlameCanvas（粒子≤300+离屏贴图+emitAt）→ CodeDissolve（逐行溶解联动粒子）→ RebirthCode（金色打字机+跳过）→ ObituaryCard（html2canvas 导出 PNG）
- [ ] T5 主页面：stage 状态机 input→causes→autopsy-loading→report→pk→flame→rebirth→card；木鱼声（Web Audio 合成+静音开关）；黄条降级提示
- [ ] T6 测试：schema.test.ts（样例 JSON 解析+正则兜底）、style.test.ts（禁词表扫 demoData+prompts），`npx vitest run` 全绿
- [ ] T7 `npm run build` 通过；`npm run dev` 启动后用真实 key 跑一场完整葬礼冒烟
- [ ] T8 README（简介/快速开始/环境变量/部署）、git init、提交前检查 .env.local 未被跟踪

## 关键接口契约（前后端 & 各任务共用）

```ts
// POST /api/autopsy → 200
{ "fallback": false, "autopsy": { language, lines, time_of_death, direct_cause, premortem: string[], smells: string[] }, "epitaph": string, "reincarnation_advice": string }

// POST /api/eulogy { model, autopsy, causes } → 200
{ "fallback": false, "model": string, "vendor": string, "eulogy": string }

// POST /api/rebirth → 200
{ "fallback": false, "refactored_code": string, "changes": string[], "rebirth_as": string }
```
